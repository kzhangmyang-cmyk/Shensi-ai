# 账号运营后台与上线缺口

当前进度以 `../PROJECT_STATUS.md` 为准。实现边界见
[平台账号模块](../modules/platform-administration.md)，初始源码核查与
开源比较留存于 [历史核查](../archive/account-admin-source-audit-2026-09-21.md)。

## 已确定的产品范围

神思运营者使用独立后台管理企业客户、账号、套餐授权、操作日志四页。
客户使用试用版／基础版／专业版；实际模块、期限、席位和价格由运营决策，
不预设未经确认的套餐差异。初始三套餐全部为未发布草稿。

源码已接入独立运营身份和TOTP、企业状态与到期、版本化套餐、服务端与
执行端授权、企业成员创建、停用/恢复/撤销会话、一次性改密、离线MFA恢复、
审计搜索、事务审计与失败回滚。已有客户不自动纳管，
已运行窗口不因源码修改自动更新。未执行真实部署或客户授权变更。

## 剩余上线阻断

| 范围 | 必须完成的工作 |
| --- | --- |
| 运营闭环 | 老客户显式纳管、运营成员管理；真实运营者身份核验与恢复流程演练 |
| 审计与规模 | 补脱敏前后值、请求关联/结果、日期/动作专项筛选和导出；已有操作者/动作/目标/原因搜索。评估聚合JSON增长，现有revision冲突保护不是幂等结果重放 |
| 套餐规则 | 确认模块、默认天数、席位；价格/用量配额尚未实现。套餐不得替代客户角色与外联审批 |
| 境外生产 | 常驻计算、持久MySQL、固定HTTPS域名、静态运营入口、备份调度和告警；免费Render保留联调用途 |
| 发布方式 | 首发单API实例、维护窗口；扩容前改造整体快照写入、共享限流/失效及worker所有权，不能只删除实例锁 |
| 恢复与云迁移 | 真实目标版本/权限/TLS适配；新空库恢复、密文解密、租户隔离、不可逆动作账本与切换回退演练 |
| 正式桌面 | 固定API地址、正式签名/公证、实际设备与WAN验收；源码build不等于安装包交付 |

上线顺序固定为：外网服务与正式运营者初始化 → 新客户注册/后台人工授权与
核心业务写入验收 → 同一API的桌面测试包跨设备验收 → V1.0正式安装包。
可复核步骤及禁止混用本机合成数据的边界见
[账号服务常驻部署与恢复](account-admin-cloud-runbook.md#发布验收与剩余外部依赖)。

## 境外先行、后迁阿里云

Cloudflare临时路线和费用/能力边界见
[账号服务常驻部署与恢复](account-admin-cloud-runbook.md#cloudflare-免费层的临时境外入口)。
官网静态页可先用Pages免费层；产品、后台、MySQL、咨询邮件仍需要常驻资源。
未取得固定域名、目标主机/数据库及SMTP前，不把本机验收入口称为公网产品。

应用继续使用当前Express、MySQL及容器边界；通过环境配置注入数据库、密钥、
公开origin与外部服务地址。首发采用单实例维护窗口，数据库备份与长期密钥
分开保管。浏览器Profile与用户本机执行仍留在桌面，不复制到服务器。

阿里云阶段使用同版应用镜像与兼容MySQL目标，先验证建表权限、TLS、字符集、
时区与连接配置。保留旧库，恢复到新的空库并验证schema清单、记录数、加密资料、
MFA与权限、历史任务状态。切换前停写并停止新执行领取；外部已发送任务只对账，
不因迁移重发。切换后若已有新写入，不能直接将流量切回旧库：须先处理写入差异。

本地合成MySQL备份恢复演练只验证程序路径，不替代受管云目标和真实数据验收。
详细操作约束见 `../DEPLOYMENT.md` 与 `../DATA_MIGRATION.md`。
