# 星盘交互界面设计规格

## 范围

保留最新Shensi桌面公共壳和真实业务接口。经营模式覆盖企业资料、多文件引用、事实校对、五角色、100情景、报告、导出与历史回放；创业模式独立接入原算法，不把其随机起点混入经营基线。

当前视觉参考为`input-premium-v2.png`、`replay-premium-v2.png`与`analysis-galaxy-v2.png`。旧concept图仅保留设计过程，不作当前实现目标。图稿中的数值、文件与结论都是占位，不作为真实计算证据。

## 视觉系统

- 黑绿背景`#090e0c`、面板`#101915`、结构线`#26362e`。
- 正文`#e6eee9`、次要文字`#b0c1b7`、交互强调`#42dd9b`。
- 遵循现有桌面系统字体。标题22px，模块16px，控件/正文13–14px，说明不小于12px；数值使用tabular-nums。
- 紧凑工具密度，8/16/24间距，结构面板8px圆角。星系装饰仅用于用户要求的真实模型分析阶段；输入与结果页不使用装饰粒子。
- 原生按钮、输入、选择框、折叠控件；可见焦点，不用图片承载文字和操作。

## 资料校对

资料页以双栏显示真实选中文件、格式/大小、读取状态、原引用与可编辑经营起点；历史在顶部展开。来源状态区分候选、冲突与缺失。下方来源核对区显示当前字段原文和位置，可明确选用候选；缺失值不自动置零，全部八项经营输入保留。

应收应付、备选方案和随机假设可展开；模型使用确认与资料解析分离。五角色状态仅采用服务端实际状态，不做虚假百分比。失败说明恢复方式，保留输入。

图稿中的示例文件日期、用户头像、使用说明、批量编辑及在文件中定位属于生成器附加项，不作为已实现功能；实现使用真实文件信息和现有账户壳。不复制示例历史记录。

## 100情景回放

单一标题、五阶段条、报告上下文和连续摘要条构成顶部。主画布约72%、右侧月度详情约28%；完整100格在右栏折叠，播放控制放在图下。五角色依据与真实基线经营盈亏平衡放到下方两列。利润范围独立展示，不把利润称作现金。没有计算的分位带、具体天数预警与建议不照抄图稿。

图形只能读取保存记录的`report.replays`。每条线表示一个样本的月末现金，全部方案和月份共用固定纵轴，零现金独立标线。100个编号按钮选择单情景，选中状态不只靠颜色；键盘方向键移动、Enter/Space选择，并保留原生样本下拉作为等效入口。

播放是计算完成后的结果回放，不是计算进度。默认暂停；支持播放/暂停、直接拖动月份、速度和方案选择。页面隐藏、离开或记录替换时停止计时。reduced-motion默认没有动画，并保留逐月操作。高频控件不延迟，不强制等待装饰性动画。

现金不足状态按当前月真实值判断，不提前显示未来失败；总体缺口统计保留其完整路径口径。选中情景的表格和图形使用同一索引。方案比较必须使用同一情景编号和月份，不重新抽样。

## 智能体分析动效

`analysis-view.ts`使用无文字生成资产`assets/galaxy-cyan-brand.png`，对应用户选择的`galaxy-cyan-brand-v5.png`。深黑青星云、中央三旋流与上1下2电弧球构图固定，不旋转底图；原椭圆轨道隐藏。黑绿产品外壳、五角色标签和真实状态保持独立。`galaxy-dust.ts`用Canvas呈现4400青白粒子（画布宽不足600时2200），近正面五臂、7.2旋绕，前中后三层粒径/亮度/速度不同，同层内部较快、外部较慢；三球只叠加原素材局部亮度呼吸，30fps绘制上限、DPR不超过2。实际running圆形节点2秒弱脉冲，完成实心稳定、等待低亮空心、失败明确。装饰不更新完成数、角色状态或计算百分比；后台、离页与手动/系统减少动态时取消动画帧，恢复不补跑后台时间，卸载断开尺寸监听。完成结果不为装饰效果延迟展示。

回放图表高度使用`clamp(220px,100dvh - 570px,380px)`，预留标题、指标、选择器、播放条与状态文本空间，坐标字号16（SVG内部单位）。低高度或更窄的窗口保留220px图表和自然纵向滚动，不隐藏控件。隔离回归入口`frontend/tests/decision-replay-visual.html`使用真实组件与明确合成数据，提供“对照旧高度预算”验证红绿差异，不调用API或模型。

失败的本次任务允许明确重试相同资料与已校对输入，服务端重新执行五角色；运行中与已完成任务的重复请求保持幂等，改变输入仍冲突。没有自动重试或隐藏模型费用循环。

## 验证要求

先通过存储结果映射、固定比例尺、索引边界和不变性测试，再验证播放暂停、月份、方案、样本、键盘、离开清理和reduced-motion。原生桌面验证真实保存报告；隔离浏览器测试可使用明确合成记录，不写CRM或旧外联队列。

最终须对照概念与当前截图检查布局、排版、配色、控件与交互，并记录有意偏差；不能仅凭构建成功宣称视觉验收完成。
