## 未通过及基线缺陷

- 根级 `npm run test` 退出码为 1；后端基础测试在 `backend/src/self-test.ts:181` 失败，错误为 `ai config delete failed`。
- 根级测试脚本采用 `backend && frontend`，因此该次根级命令没有执行前端测试；上述前端结果来自控制器的独立补跑。
- 已确认根因：两个无显式 ID 的 AI config POST 在同一毫秒内可能因 `Date.now()` 生成相同 ID；内存 store 不保证 ID 唯一，而 DELETE 仅删除首个匹配项，导致同 ID 配置残留。诊断有效样本为 8 次通过、1 次失败，冻结时钟的真实 HTTP 观测确定性复现了完整链路。
- 相关实现与 Gitee 1.09 基线 `origin/master` 一致，缺陷并非本次文档集成提交引入。
