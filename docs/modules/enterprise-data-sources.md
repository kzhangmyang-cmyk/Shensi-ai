# 企业公开数据源

核查日期：2026-09-14。网页可免费搜索不等于API可免费复用；试用不等于长期免费。

## 已接入：GLEIF补充来源

[官方API介绍](https://www.gleif.org/en/lei-data/gleif-api)、[官方文档入口](https://api.gleif.org/docs)、[开放数据许可](https://www.gleif.org/en/about/open-data)。官方提供公开API，数据CC0，当前小量调用无需密钥。此来源只覆盖已登记LEI的法律实体，不是全国工商库，不能承担全国中小企业按行业获客。页面明确标注此边界，不提供虚构电话、行业、规模、资本。

产品通过认证后的 `GET /api/enterprise-query/gleif?keyword=银行&page=1` 查询。服务端固定官方HTTPS地址及中国国家过滤，名称2–100字，十条一页，最大页码1000，10秒超时，不跟随重定向。使用来源分页总数，单页按LEI去重；显示登记资料更新时间。只在用户查询/翻页时请求，不后台抓全库，不保存CRM、不执行外联。上游限流、错误和无结果分开显示。没有搜索结果不能推断企业不存在。

服务层实际匿名小量调用“银行”成功，首页10条、总数3796、Golden Copy日期2026-09-14；数量是当时返回值，不固定写进产品。

## astrbot_plugin_bizjob 核验

[源码](https://github.com/KardeniaPoyu/astrbot_plugin_bizjob)固定核验提交 `717b994455b2283cb93805a280bda084d21f6a24`，提交日期2026-09-11，核查时仅一个提交，维护持续性尚无历史证据。仓库MIT许可，版权为2026 KardeniaPoyu；如复用实质代码须保留许可及归属。源码许可不代表第三方平台的数据使用授权。

2026-09-14在本机发出一次无Cookie GET `/s/advanceFilterAjax?q=哔哩哔哩&p=1&s=5&t=0`，使用JSON Accept、XHR及正常搜索页Referer，保持TLS验证，无代理轮换、重试或验证码绕过。返回HTTP 200、`application/json`，但业务 `status=-14`，消息指向百度wappass图形验证码页，data仅包含验证参数，没有企业resultList。未查询详情接口，也未把验证参数保存进代码或文档。结论：该新JSON入口存在，但当前匿名请求受验证拦截，尚未接通企业数据，不能将响应作为空结果或成功。

源码 `aiqicha.py` 的 `_unwrap` 只将 `-1`、`1001` 或含中文登录/验证的消息判作Blocked；本次 `-14` 加验证码URL会误归一般上游错误。搜索把缺失data或resultList兜底为空，无法严格区分协议变化和真实零结果。后续适配须校验业务成功状态和列表结构，单独展示需人工验证、限流、网络失败与合法空结果；不可直接照搬兜底。`http.py` 有TTL缓存、实例限速、超时和TLS正常校验，可参考这些边界，但不采用默认自动回退到收费来源的产品行为。

用户完成Chrome登录后，官方搜索页“哔哩哔哩”可显示575个相关结果、首页10张企业卡片，且明确当前展示40条、更多需会员。这证明当前浏览器会话可访问页面，不证明匿名JSON接口已可用。专用本机桥接实现见 [安装与验收说明](../../desktop/enterprise-bridge/README.md)，真实10条已进入本机预览，只读取当前页公开呈现字段，不继承/复制Cookie、不使用Codex扩展作产品依赖。Electron内置窗口试点复用同一字段解析，首次登录及网站兼容性独立验收。招聘功能不在接入范围内。

2026-09-14 对同一企业“郑州长通塑业有限公司”的来源核对：GLEIF 返回登记编号、邮编、LEI状态，已映射展示，但未返回法人、资本、电话、行业和经营范围。内置爱企查正常登录后列表提供法人/资本/日期/电话/地址，详情还公开信用代码、企业类型、行业、参保人数、邮箱和经营范围；这些可见字段已接入显式详情读取。核准日期被网站遮蔽，不提取。两个来源的成立日期原始表达不同，分别展示，不把一方数据无来源地写入另一方。
