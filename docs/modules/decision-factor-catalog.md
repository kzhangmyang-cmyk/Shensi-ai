# 经营因素库与决策风格

## 证据用途

本库用于选择建模维度，不把文献结果直接转成某家企业的事件概率或利润系数。NBER的[管理实践研究](https://www.nber.org/papers/w16658)研究了印度纺织企业的管理干预与质量、效率、库存；它支持纳入运营管理维度，不证明所有行业具有同一效应。[OECD中小企业数字化专题](https://www.oecd.org/en/topics/digitalisation-of-smes.html)提供数字化及资源能力背景。下表为产品建模候选分类，不是这些来源逐项验证过的因果关系。

## 覆盖矩阵

| 类别 | 长期特征 / 可控决策 / 随机事件举例 | 数值接入状态 |
|---|---|---|
| 人员 | 岗位依赖；培训安排；缺勤、熟练度变化 | 显式缺勤/熟练度事件仅替代交付效率；不含招聘培训成本 |
| 管理 | 授权、审批链；流程调整；信息延迟 | 候选，未建模 |
| 销售 | 渠道结构；营销配置；新增订单升降 | 渠道需求事件替代订单倍率；漏斗、销售周期与营销费用未拆开 |
| 客户 | 集中度；维系策略；流失、复购 | 候选，未独立建模，不从需求曲线推断客户流失 |
| 定价产品 | 产品组合；价格决策；季节需求 | 静态方案价格倍率已有；多品类和季节机制未建模 |
| 质量售后 | 缺陷率；质检投入；退货返工 | 候选，未建模 |
| 产能设备 | 设备依赖；扩容排程；停机 | 静态产能已有；设备事件未建模 |
| 供应库存 | 供应商结构；备货；价格、物流变化 | 采购单价涨跌事件已有；库存、物流和供应商延误未建模 |
| 回款融资 | 赊销条件；授信策略；客户延期 | 新增应收延期/恢复基准账期事件已有；坏账、借贷偿债未建模 |
| 费用扩张 | 固定支出；扩张投资；维护开支 | 静态额外固定费已有；动态投资费用未建模 |
| 系统数据 | 数字化程度；系统投入；中断 | 候选，未建模 |
| 外部日常环境 | 行业竞争；渠道选择；平台与能源变化 | 候选，未建模；不启用战争等重大灾难模板 |

特征是基线信息，决策是可控方案，事件是路径中的条件变化，三者不能统一随机抽样。事件模板只由用户确认适用，不从行业名称自动推断。当前模型没有设备/员工/客户分项数据，不对所有企业强套全部模板。

## 当前事件口径

8个模板覆盖人员、销售、采购、回款的正负向代表情形，默认无事件。每模板最多一次，每条样本在指定起始月按假设概率抽取一次，发生后保持指定持续月数；概率不是逐月概率。每模板独立随机流，以seed、样本编号和模板标识确定，不受方案顺序或模板列表顺序影响。各方案共享最终外生路径。

生效月的事件值替代对应背景因子，未生效月保留背景；保存被替代值、最终值、时间窗和假设。这样避免同一原因被背景和事件重复扣减，也意味着生效月该因子不再保留背景共同扰动的相关结构。同因素重叠时间窗和同模板重复一律拒绝，即使概率为0；用户调整后再生成。不同因素的事件发生暂按独立流处理，没有共因事件相关/自动连锁事件机制；业务传导仍由订单、交付、收入、回款和现金的计算链承担。

恢复基准账期表示额外延期0，不提前基线账期、不追溯旧应收。人员熟练度事件只表达预期效率变化，不把培训行为及其成本一并模拟。每个模板需说明依据；默认值是可调演示假设。现有敏感性分析扰动最终因子，不重新抽取事件，不是事件贡献金额归因。

## 决策偏好：本次报告确认

自愿填写、可跳过、可编辑确认。候选维度为现金底线/风险承受、响应速度、证据与试点偏好、授权、扩张倾向、止损调整规则。不得从聊天或企业资料暗推人格，不用MBTI决定利润或评判人格优劣。

当前输入可选现金/利润/交付优先、现金底线、先试点与复盘频率；显式确认后随本次报告加密保存。服务端按最差现金/最低利润/最大积压排序，并核对所有样本是否满足现金底线；不改变经营利润或随机路径。响应滞后、触发扩容/减支/调价需要独立行动规则、资金约束及逐月日志，尚未建立。未填写使用原固定方案，不推断性格。

本次反馈候选默认关闭，开启后只从用户显式选择“更看重现金/利润/交付”形成候选，二次确认才采用。可查看、修改、清除本次偏好或关闭候选；报告保留self_report/explicit_feedback来源与报告创建时间。清除当前输入不删除历史快照。跨会话个人档案可显式保存、采用、关闭、删除和导出；实际执行复盘独立记录计划/手填结果，仅明确反馈形成待确认偏好。不从聊天推断人格或后台自动学习。偏好不等同能力，客观风险仍显示。

## 降本增效建议

建议必须进入保存报告结构，再由页面与HTML导出读取同一份数据，而不是导出时临时添加固定文案。每项包含问题与真实依据、建议动作、影响机制、执行成本/前提、优先级、负责人角色、周期、验收指标和复盘条件。区分模拟方案比较支持的建议与模型待验证建议；原资料/人工确认/规则计算引用继续分开。

按资料适用性考虑采购库存、回款、交付排程、返工、流程自动化和营销渠道效率。未建模领域只给待核实事项或小范围试点，不能称已计算节省。金额、收益区间和回收期必须有输入及计算依据，并分开一次性成本与持续费用；没有依据不填ROI、不保证收益、不用虚构数字排序。降本不默认裁员，质量、客户体验及交付约束是验收前提。当前导出为HTML，不声称已实现PDF。

当前规则建议依据已确认基线及模拟信号选择回款、采购、交付、单位贡献或需求验证；保存证据位置与完整行动字段，页面/HTML同源展示。行动效果为待试点；模型五角色意见仍单列，不伪装成已计算收益。旧报告不补写。跨会话偏好和明确确认式手动复盘已接入；自动因果归因、训练和动态行动规则尚未实现。
