# 企业查询

macOS源码版提供“打开爱企查”独立内置窗口：首次由本人正常登录、搜索，再点击“读取内置浏览器当前页”显示来源、读取时间及去重后的实际条数。窗口复用 Electron Chromium，不要求安装 Chrome。每个 Shensi 账号在当前后端身份下拥有独立持久 session，不读取或复制 Chrome Cookie。窗口无 Node/preload 权限，限制 HTTPS 网站及百度登录页导航；验证码与网站阻止必须正常处理，不自动绕过。
页面以该内置窗口为默认操作路径；“可选 · 读取 Chrome 扩展预览”仅供已经自行安装 Chrome 扩展的用户使用，不是企业查询前置条件，也不支持 Safari/Firefox/Edge 扩展会话。

“筛选已有资料”只对已加载本地资料过滤，旁边显示原始条数与范围；没有资料不等于在线没有企业。主要在线入口为“普通搜索 · 爱企查”：使用本人独立会话打开网站普通关键词搜索，等待当前页可见卡片后自动回传主列表与详情。它仅使用输入的2–200字关键词，明确不应用地区、行业、规模，也不把条件拼成关键词；不需要先尝试付费高级搜索。网站数量、登录及验证限制仍生效，保留显式读取当前页作为兜底。

折叠的“高级条件查询（需要网站权限）”将关键词、省市路径与行业路径分开传给本机 Main。Main 打开网站高级搜索，清除当前筛选、操作已呈现控件，核验地区标签与行业叶子复选框后提交；不调用私有接口或读取网站隐藏状态。IPC不接受任意URL或脚本。普通搜索不是高级搜索的自动降级，两者由用户显式选择。

网站高级搜索仅提供门类/二级行业，产品四级目录的更深节点在此来源明确拒绝，需用户选择上级；不会自动放宽。站点缺少同名地区/行业也停止。产品人数规模与网站大型/中型/小型/微型不是同一口径，不能直接映射。当前账号实测点击高级搜索结果出现“开通超级会员 解锁高级搜索”：不购买、不绕过、不以其他查询假装成功。登录、人工验证、查询次数、会员权限或页面变化均明确报错；成功结果只读取当前已展示页面，最多40条，不自动翻页。

普通搜索首批回传后，可显式点击“加载更多企业”：每次只点击网站原生下一页并读取一页，按公开企业详情标识或规范化名称去重追加，保留已选详情。Main批次绑定账号、窗口及关键词，核验实际页码与卡片变化；失败保留已有结果，待完成页重试不重复翻页，新搜索清空批次。达到网站末页、会员或验证限制时停止并显示原因，不预设总条数，不无界后台遍历。网站每页1–40条的校验与累计结果分开。

内置浏览器读取、扩展读取及条件查询成功的资料共用产品主列表/详情。字段使用桌面EnterpriseCapture契约，缺失显示“当前页未提供”，参保人数不当员工总数。资料仅本机本次展示，不生成CRM标识或自动入池；关闭预览或切换来源后丢弃迟到读取结果。已有线索列表与网站可见资料不静默合并。

Chrome 扩展预览仍作为可选入口保留，真实10家企业链路已验证。内置与扩展复用同一可见DOM读取脚本及字段校验，仅本机预览、不自动入池；首次内置网站登录验收状态见当前项目状态。见 [本机桥接](../../desktop/enterprise-bridge/README.md)。

数据来源可选已有企业资料或免费GLEIF中国LEI补充源。后者必须输入企业名称后查询，分页来自上游，详情显示LEI、来源登记编号/登记机关代码、登记地址、邮编、LEI续期状态和来源更新时间。LEI续期逾期不等于工商注销；来源编号不自动归类为统一信用代码。不提供全国工商库、行业或电话搜索，不自动入客户池。来源许可、接口与国内候选凭证要求见 [企业公开数据源](enterprise-data-sources.md)。

内置爱企查支持当前搜索列表或本人打开的企业详情页。详情只读已展示工商表和联系区，增加信用代码、企业类型、行业、参保人数（非员工总数）、公开邮箱和经营范围，以折叠资料显示。遮蔽字段不猜测，不读取付费隐藏内容，不自动逐家翻页。列表地址去除风险统计及股东信息等导航文字；不同来源的日期与资料独立展示，不静默合并。

## 隔离前端预览

网站资料列表页脚显示当前记录范围及累计条数，空结果显示0页和重新读取提示。详情可用关闭按钮或Esc收起，焦点返回原企业行（跨页后返回列表）；切换企业将详情滚动到顶部，追加读取结果保留当前阅读位置。翻页从列表顶部开始，不自动打开下一家企业。

筛选区展示当前关键词、地区完整路径、行业完整路径与规模标签，可逐项清除，选择器与标签同步；重置清除全部条件。网站资料详情按工商资料、地址与联系、经营范围分组，名称、公开联系方式、邮箱与信用代码可显式复制，失败提供手动复制提示。已有资料详情支持名称和联系方式复制。读取过程中禁止重复读取并展示忙碌状态，失败提供原操作重试按钮。宽屏列表与详情分别滚动，列表标题和翻页栏固定；窄屏按上下布局自然滚动。网站查询范围与已有资料筛选范围不合并。

交互细节：可一键重置筛选、清空勾选；详情页签支持左右方向键及 Home/End。入池反馈直接显示在详情内，预览明确标注模拟成功、不写真实数据，不再弹出阻断操作的 alert。键盘焦点可见，系统减少动态效果设置生效。

运行 `pnpm --dir frontend exec vite --mode desktop --host 127.0.0.1 --port 5188 --strictPort`，打开 `http://127.0.0.1:5188/enterprise-preview.html`。该开发页注入六家明确标注的示例企业，搜索、详情页签可操作，入池仅显示模拟反馈，不调用真实 CRM。生产入口不载入此页或示例。

地区使用全国省级→地级单位级联，34省级、333地级及单独标注的省直辖县级入口，不提供一般区县筛选；支持名称搜索、切省清市、不限与重置。直辖市直接按本市选择，港澳台不补造下级。目录基准与数据源过滤能力见[地区数据](enterprise-region-data.md)。行业使用国民经济行业分类四级选择器，支持名称/代码搜索、完整路径、上级包含下级、不限行业及重置；不推断未提供的分类。分类来源和范围见[行业数据](enterprise-industry-data.md)。勾选列支持逐条与本页全选，只改变选择状态，不提交批量操作。完整基本字段及经营范围可查看，未知内容显示“未提供”。添加 `?pagination=1` 可测试12条隔离分页样例。宽屏/窄屏、筛选、页签、勾选和模拟入池已做浏览器验收；截图在 `../desktop/screenshots/enterprise-query/`，根 `design-qa.md` 的通过结论仅限此前端预览。

桌面源代码入口为左侧导航「企业查询」（`#enterprise-query`），复用现有黑绿应用外壳，不产生独立安装包。

搜索按企业名称、业务和简介匹配，地区、行业组合筛选。列表每页 10 条，点击行打开右侧基本信息、经营信息、联系方式页签；窄屏详情位于列表下方。当前只读取已授权的 `/api/tools/website-opportunities` 数据，后端现有 owner/team 权限生效，排除项不显示。没有资料时显示空态，不写入示例企业。

已有企业线索来源未提供的统一信用代码、成立时间、规模和注册资本显示「未提供」，不从线索创建日期或公司名称推断。选择规模筛选时未知规模不匹配。GLEIF仅映射其明确返回的实体成立日期、地址和LEI状态；LEI状态不是工商存续结论。用户后续提供数据时需明确字段映射与导入范围。

已具有 tenantProspectId 和 leadId 的企业，可通过现有 `/api/prospects/:id/convert-to-customer` 加入客户池，复用其身份隔离、去重与幂等处理。点击才提交；重试使用同一幂等键。没有已核验线索的企业显示原因且禁止提交，不绕过现有线索核验规则。

验证：`pnpm --dir frontend exec tsx --test src/enterprise-query/model.test.ts`；`pnpm --dir frontend exec tsc --noEmit -p tsconfig.json`。

普通搜索只支持关键词：存在地区、行业或人数规模条件时在调用桌面桥之前阻断，保留条件并说明需要高级查询或显式清除；不静默忽略条件。高级查询仅映射省市和门类/二级行业，网站权限不足时停止。GLEIF入口仍仅支持中国LEI范围的名称查询，切源清空并隐藏不支持的筛选项，不将其他来源条件带入。

历史验收：源码65103实测“塑料”首批10家，第2页新增10、第3页新增9（重复1）、第4页新增10，累计39家；第5页网站提示免费机会用完，应用保留39并停止。換“橡胶”查询后仅显示新批次10家。此为该账号/关键词本次实际范围，不是全站固定上限。全国地区郑州路径在56010原生验证。高级条件查询当前账号受会员要求阻塞。真实入池验收、企业资料持久化导入尚未完成，现有线索适配不替代普通企业导入。当前回传资料不会调用CRM。
